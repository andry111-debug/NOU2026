Fedstat Research Workstation N_106

Назначение
Программа для загрузки таблиц Fedstat/ЕМИСС, работы с фильтрами и визуализации региональных данных на карте РФ.

Что изменено в N_103
1. Вкладка карты упрощена: вместо прежнего блока базовой карты оставлены две основные кнопки: «Открыть только карту» и «Открыть карту с параметрами».
2. Параметры карты с показателями перенесены во вкладку «2) Карта».
3. Отдельная вкладка «3) Карта параметра» удалена из интерфейса.
4. Из вкладки карты убран встроенный Matplotlib-просмотр, так как карта открывается в отдельном окне PySide6 WebView + MapLibre.
5. Кнопка «Взять из списка загрузок» теперь переносит выбранный файл в параметры карты и открывает вкладку «2) Карта».

Запуск
1. Установить зависимости:
   pip install -r requirements.txt
2. Запустить:
   python main.py

Примечание
Карта использует PySide6 WebView + MapLibre GL JS. Для отображения WebView-карты нужен доступ к CDN MapLibre или локально доступная копия MapLibre, если вы доработаете HTML под локальные файлы.

N_105 — контекстное построение карты из списка файлов

Во вкладке «2) Карта» добавлена кнопка «Построить волновую функцию инфляции».

Порядок работы:
1. Выберите файл данных XLS/XLSX/CSV/XML/SDMX в параметрах карты или нажмите «Взять из списка загрузок».
2. При необходимости задайте период и ключ строки. Если поля пустые, программа выберет подходящие значения автоматически.
3. В поле «Масштаб» можно задать начальный коэффициент высоты поверхности. Для индексов около 100 обычно нужен большой коэффициент, например 30, 50 или 100.
4. Нажмите «Построить волновую функцию инфляции».
5. В новом окне можно вращать сцену мышью, приближать колесом, отключать карту и менять коэффициент высоты без повторного чтения файла.

Логика построения:
- значения берутся из таблицы по регионам;
- опорные точки размещаются над столицами регионов;
- высота считается как отклонение значения от среднего по сопоставленным регионам, умноженное на коэффициент;
- поверхность строится интерполяцией между столицами регионов;
- карта и красные границы служат подложкой под поверхностью.

Требуется Plotly. Установите зависимости командой:
    pip install -r requirements.txt

Изменения N_105:
- В контекстное меню списка загруженных файлов добавлен пункт «Построить».
- При выборе пункта программа переходит во вкладку «2) Карта».
- Выбранный файл автоматически подставляется в поле «Файл данных».
- Существующий пункт «Открыть папку файла» сохранен.


N_106 — управление городами и прозрачностью волновой поверхности

Изменения N_106:
- В окне волновой функции добавлена правая панель со списком городов.
- Каждый город можно включать и отключать отдельным флажком без перестроения поверхности.
- Добавлены кнопки «Все» и «Скрыть все» для быстрого управления городами.
- Добавлено регулирование прозрачности поверхности.
- Добавлено регулирование прозрачности карты-подложки.
- Добавлено регулирование прозрачности городов и вертикалей к точкам.
- Коэффициент высоты по-прежнему меняется прямо в окне графика.

Примечание:
Отключение города в панели влияет на отображение точки, подписи и вертикали. Поверхность при этом остается построенной по исходному набору региональных значений, чтобы пользователь мог убирать визуальный шум без пересчета модели.
