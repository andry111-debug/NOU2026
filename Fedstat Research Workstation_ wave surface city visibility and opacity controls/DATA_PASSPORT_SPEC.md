# Паспорт данных M1

Паспорт данных нужен, чтобы каждый фактор перед автоподбором был не просто файлом, а проверенным исследовательским объектом.

## Поля паспорта

| Поле | Смысл |
|---|---|
| `factor_id` | Стабильный идентификатор фактора внутри лаборатории. |
| `name` | Человеческое название показателя. |
| `role` | Слой индекса: тело, среда или цель. |
| `subtype` | Более точный тип: продовольствие, топливо, производство, доходы, логистика и т.д. |
| `source_name` | Источник данных: Fedstat, Росстат, Банк России, ручная таблица, внешний файл. |
| `frequency` | Частота ряда: месяц, квартал, год. |
| `level` | Уровень данных: регион, федеральный округ, РФ. |
| `period_start` | Первый период, доступный для расчёта. |
| `period_end` | Последний период, доступный для расчёта. |
| `units` | Единицы измерения. |
| `value_description` | Что именно означает колонка `value`. |
| `expected_sign` | Ожидаемый знак влияния на целевую инфляцию: плюс, минус, неоднозначно, не задан. |
| `allowed_lags` | Лаги, которые разрешено проверять в автоподборе. |
| `quality_status` | Качество данных: черновик, проверено, есть пропуски, сомнительно. |
| `missing_policy` | Что делаем с пропусками: не проверено, удалить, интерполировать, заполнить нулём, ручная обработка. |
| `passport_status` | Статус допуска: требует заполнения, готов к разведке, готов к автоподбору, исключить. |
| `note` | Комментарий исследователя. |

## Критерий готовности M1

Этап M1 можно считать выполненным, когда для стартового набора факторов:

- заполнены источник, частота, уровень, период и единицы;
- понятно, что означает `value`;
- назначен слой индекса;
- задан ожидаемый знак или явно указано, что знак неоднозначен;
- указаны допустимые лаги;
- описаны пропуски и качество данных;
- фактор получил статус `готов к разведке` или `готов к автоподбору`.

## Правило допуска в автоподбор

В автоподбор v1 должны попадать только факторы со статусом:

- `готов к разведке`;
- `готов к автоподбору`.

Факторы со статусом `требует заполнения`, `черновик` или `исключить` нужно показывать в каталоге, но не использовать в автоматическом подборе без явного разрешения.
