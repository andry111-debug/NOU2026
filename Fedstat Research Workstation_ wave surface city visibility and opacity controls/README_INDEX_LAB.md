# Лаборатория индекса инфляционного импульса — N_001

Отдельное приложение для сборки, ручной проверки и первичного автоматического подбора индекса, который коррелирует с будущей инфляцией и распространяется между регионами во времени.

## Запуск

```text
run_index_lab.bat
```

или напрямую:

```text
python index_lab_qt_app.py
```

Файл `index_lab_qt_app.py` — основная версия лаборатории в стиле Fedstat Research Workstation 2.0: боковое меню, розовая тема и стартовый экран с блок-схемой. Файл `index_lab_app.py` оставлен как ранний Tkinter-прототип.

План исполнения зафиксирован в `ROADMAP_INDEX_LAB.md` и продублирован в экране **«Роадмап»** внутри лаборатории. Формат M1 описан в `DATA_PASSPORT_SPEC.md`, а заполняется на экране **«Паспорт данных»**. Очередь поиска данных зафиксирована в `DATA_NEEDS_ROADMAP.md` и экране **«Потребность в данных»**.

## Загрузка данных Fedstat

Для повторной загрузки стартовых пакетов используется единый headless-загрузчик:

```text
python fedstat_lab_downloader.py 300
```

Он переиспользует парсер фильтров и сбор payload из базовой программы, скачивает показатель Fedstat 31074 и приводит данные к формату `region / period / value`.

Сейчас загружены:

- `D01-D04` — целевые ряды ИПЦ;
- `D05-D08` — стартовые кандидаты тела: продовольственные/непродовольственные группы, топливо и транспортные услуги.

Результаты лежат в `data/fedstat_targets/processed/`, журнал загрузки — `data/fedstat_targets/download_manifest.json`, первичный контроль качества — `data/fedstat_targets/quality_summary.csv` и `data/fedstat_targets/quality_flags.csv`.

## QC и первый автоподбор

После загрузки данных и региональной гармонизации первый воспроизводимый прогон выполняется так:

```text
python index_lab_qc.py
```

Скрипт проверяет 85-региональную панель, назначает допуск факторов, строит проверку горизонтов 1/2/3/6 месяца, записывает стартовый рецепт в `settings/index_lab_recipe.json` и отдельно считает матрицу чувствительности по всем целям и горизонтам.

Текущий основной результат v0: 13 факторов допущены, 5 временно исключены; цель `target_ipc_food`, горизонт 1 месяц; корреляция `0.154`, точность направления `0.548`.

Матрица чувствительности v0 показывает, что лучший текущий сценарий — `target_ipc_food` на горизонте 6 месяцев: корреляция `0.199`, точность направления `0.561`. Это базовая разведка, а не финальная модель: следующий шаг — дробить тело индекса и добавлять среду.

Главные выходы:

- `data/fedstat_targets/qc_report.md`;
- `data/fedstat_targets/qc_decisions.csv`;
- `index_lab_output/auto_selection_v0_scoreboard.csv`;
- `index_lab_output/auto_selection_v0_recipe.json`;
- `index_lab_output/auto_selection_v0_metrics.json`;
- `index_lab_output/auto_selection_v0_result.csv`.
- `index_lab_output/auto_selection_v0_sensitivity.csv`;
- `index_lab_output/auto_selection_v0_sensitivity.md`;
- `index_lab_output/auto_selection_v0_sensitivity/`.

## Региональный слой

Для повторной загрузки геоосновы и сборки маппинга Fedstat-регионов:

```text
python region_harmonizer.py
```

Скрипт скачивает ADM1-границы geoBoundaries и CSV-справочник субъектов, затем строит `data/geo/fedstat_region_harmonization.csv`. В расчете лаборатория автоматически использует этот маппинг: 104 Fedstat-наименования приводятся к 85 субъектным регионам, а экономические районы, исторические округа и частичные региональные строки исключаются из субъектной панели.

## Идея

Индекс собирается из трёх смысловых слоёв:

1. **Тело** — товарные и ценовые факторы, из которых состоит импульс.
2. **Среда** — региональные условия, усиливающие или гасящие восприимчивость.
3. **Транспорт** — каналы распространения между регионами: расстояние, федеральный округ, будущие логистические слои.

В текущем MVP используется единая формула:

```text
индекс = тело + среда + транспортированный лаг тела
```

## Формат факторов

Каждый фактор загружается из CSV/XLS/XLSX и должен иметь как минимум три выбранные колонки:

```text
region | period | value
```

Названия колонок могут быть другими: они выбираются в интерфейсе при добавлении фактора.

Примеры факторов:

- индекс цен на продовольственные товары;
- индекс цен на непродовольственные товары;
- бензин / дизель;
- транспортные услуги;
- валютный курс, если он задан как региональный или общий фактор;
- региональная производственная мощность;
- целевая продовольственная инфляция.

## Ручной режим

1. Добавить факторы в каталог.
2. Выбрать целевой фактор и горизонт прогноза.
3. Добавить нужные факторы в **тело** и **среду**.
4. Добавить один или несколько транспортных слоёв.
5. Нажать **Рассчитать ручной рецепт**.

## Автоматический режим

Автоподбор использует тот же формат рецепта, что и ручной режим.

Он перебирает факторы и лаги до 6 месяцев, оценивает корреляцию с будущей целевой инфляцией, затем записывает лучший стартовый вариант в обычный рецепт. После этого его можно вручную править.

Это не финальная эконометрическая модель, а первый инструмент отбора элементов индекса.

## Блок-схема подбора

Во вкладке **«5) Схема»** добавлена визуальная блок-схема исследовательского конвейера:

```text
данные -> цель -> шоки -> тело / среда / транспорт -> лаги -> оценка -> рецепт -> проверка -> результат
```

Блоки можно выбирать и перетаскивать мышью, связи между ними перестраиваются автоматически. Двойной щелчок по блоку открывает его содержание: входные данные, операцию, выход и текущее состояние лаборатории.

В Qt-версии лаборатории блок-схема открывается сразу на первом экране **«Схема работы»**.
